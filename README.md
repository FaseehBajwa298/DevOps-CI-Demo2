# DevOps-CI-Demo2

A minimal repository with a simple Python script for CI demos.

## Getting Started

- Ensure Python is installed (3.8+ recommended).
- Run the script:

```
python hello.py
```

You should see:

```
Hello from DevOps-CI-Demo2!
```

## Repo Contents

- `hello.py` – simple entry script printing a greeting.
